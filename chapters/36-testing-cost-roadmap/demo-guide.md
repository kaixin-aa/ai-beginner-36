# 个人知识库助手演示说明

演示对象为一个人在本机阅读少量资料。使用柳叶学习室原创虚构材料，展示文件检索和可核对引用，不上传私人文件。网页截图均来自第35章实际本机操作，失败图为明确教学模拟。

## 准备

按[项目README](../../projects/knowledge-assistant/README.md)安装依赖、准备固定编码器和配置本机密钥。在项目目录运行下面命令，浏览器打开终端显示的回环地址。第一次更新索引需要加载本地编码器。

```powershell
.\.venv\Scripts\python.exe scripts/serve.py --port 8765
```

演示当天真实模式会产生新的模型请求及费用。本轮已经保存7次真实调用，本说明不声称又执行了一轮。

不想新增费用时，可以在新的演示资料目录启动回放。页面会明确显示历史响应提示，匹配第34章的固定问题；回放保留历史用量，不计为当天新增请求。回放仍需上传对应原资料并建立索引，不用于测试新题生成质量。

```powershell
.\.venv\Scripts\python.exe scripts/serve.py --port 8765 --runtime runtime-demo --replay
```

## 五分钟演示顺序

1. 上传[设备PDF](../34-document-retrieval/data/documents/equipment.pdf)，查看资料清单，再点击更新索引。说明文档共两页、含文字，扫描件暂不支持。
2. 问“柳叶学习室投影仪一次最长借用多少分钟？”，应看到90分钟，展开来源检查第1页原句。
3. 问“柳叶学习室投影仪使用结束后，应当怎样归还？”，检查关闭电源和服务台，展开来源查看第2页原句。实际页面见[正常截图](../35-web-deployment/assets/web-answer.png)。
4. 上传guide.md及两份notice文件，更新索引。问阅读分享几点开始，检查回答同时指出14点与15点，并引用两份通知。再问无线密码，检查资料不足；问海王星轨道周期，检查空检索提示。
5. 删除一份资料时阅读确认提示，确认后查看清单及索引状态变化。更新剩余资料的索引，结束后关闭启动服务的终端进程。

资料文件均在[第34章数据目录](../34-document-retrieval/data/README.md)。若端口已占用，可人为更换端口。模型未命中、超时、错误文件与处理中反馈各有可见状态，不连续点击按钮增加请求。
