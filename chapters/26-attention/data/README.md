# 注意力教学设定

2026 年 10 月 3 日原创虚构句子“小猫吃鱼，它饱了。”，人为切分为四个 Token，暂时省略标点。输入是 4×4 单位矩阵，仅为简化投影运算。它没有来自预训练词表，也没有学到语义或位置表示。

两套 Wq、Wk、Wv 各为 4×2，Wo 为 4×4，全由本章手工指定。第一头“它”的 Q 与“小猫”的 K 点积最大，第二头与“饱了”的 K 点积最大。差异由设定产生，没有作为真实语言模型行为记录。

不加掩码时，全部四个位置参加注意力；因果版本仅允许当前与此前位置。每行按点积除以根号 2 后执行 Softmax，再汇总 V。输出是特征向量，不是下一词概率或指代正确率。

本章没有外部语料、用户文本或权重下载。结果是对教学矩阵的真实计算，PNG 和 SVG 图版均为原创。
