# Automobile 数据说明

来源为 [UCI Automobile 数据集](https://archive.ics.uci.edu/dataset/10/automobile)。署名为 Schlimmer, J. (1985). Automobile [Dataset]. UCI Machine Learning Repository，[DOI](https://doi.org/10.24432/C5B01C)。资料来自 1985 Ward's Automotive Yearbook 等历史来源，仓库捐赠时间为 1987 年，不代表当前汽车市场。

获取日期为 2026 年 10 月 3 日，使用数据页链接的[官方压缩包](https://archive.ics.uci.edu/static/public/10/automobile.zip)，许可为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。按许可保留原作者、仓库、许可与修改说明，数据使用不表示原作者认可教程。

## 原始资料与教学处理

`imports-85.data` 和 `imports-85.names` 从官方压缩包直接保存，未修改字节。[来源元数据](./source-metadata.json)记录下载链接与原始文件 SHA256。正常实验直接读取本地文件；重新获取可运行 `examples/fetch_source.py`，会访问官方站点并更新本地快照。

原表 205 行、26 列，没有标题，缺失值为问号。本章依照原说明添加列名，增加从 0 起的样本编号与从 1 起的原始行号，选择发动机尺寸、整备重量、马力为特征，价格为目标。品牌仅用于错误记录说明，不进入模型。

选定字段中，马力缺两条、价格缺四条，合计拒绝六条，保留 199 条完整记录。其他未选字段的缺失不影响本章筛选。没有填补价格，没有把缺失行悄悄当作零值。所有模型使用相同 199 条、种子 42、20% 测试比例，得到训练 159 条、测试 40 条。

数据页和获取到的原始说明没有明确列出所选字段的物理单位与价格币种。本章完整保留原表量纲，不标成美元、人民币、公斤或升，指标使用原表价格数值。此限制应随数据一起保留，外部测量接入前必须补齐单位信息。

## 结果用途

清洗表、拒绝表、训练表、逐条测试预测均位于 `../results`。原始行号可追踪到无标题数据文件。数据为公开真实记录，正文两条手算指标例子为原创虚构数字，已明确区分。

随机划分不是按品牌或时间划分，相似配置可能分布在两侧。该实验只教学比较预先指定的三种模型，不代表对未知品牌、未来市场或购车决策的预测能力。
