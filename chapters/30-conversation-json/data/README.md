# 第 30 章教学数据

[五组输入与回应](./teaching-cases.json)均由作者编制。[数据结构](./plan-schema.json)描述固定计划结构，Python 专用校验器实施相同字段限制，并增加非空白字符串、当前预算一致及分钟求和检查。

本地 TeachingReplay 按顺序返回固定文本，既没有调用语言模型，也没有对自然语言作语义转换。记录中的10、20、30个 Token 为教学占位统计，不是平台计量。五组成功、两类修复和多轮修改证明程序流程可以处理这些样例，不能证明模型稳定性或学习效果。

真实模型响应以后由独立 `live-turn-` 文件记录，所有尝试的用量单独保留。演示会话为 `teaching-session.json`，真实会话为 `live-session.json`，不会将固定回应混进真实会话。
