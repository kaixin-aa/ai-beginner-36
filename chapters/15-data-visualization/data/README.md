# 本章数据来源

learning_records.csv 是第 14 章 results/clean_records.csv 的教学快照，记录内容相同。全部记录由本项目虚构编写，不包含真实个人数据，不代表教学效果。复制日期为 2026 年 10 月 3 日。源字段与清洗政策见 [第 14 章字段说明](../../14-pandas-data-cleaning/data/fields.md)。

五条记录中三条时长已知，单位为分钟。两条未知时长分别保留 missing 与 invalid_text 标记。完成状态用 True 与 False 保存，不以缺失时长推断完成状态。source_row 只是第 14 章输入文件的定位信息，不是学习日期或学习顺序，不参与相关性计算。

本章三个分析问题都使用这一份快照。直方图和散点图只使用时长已知的三条，分组完成统计使用全部五条。分析输出保留输入文件 SHA-256，便于确认后续运行使用了同一份文件。
