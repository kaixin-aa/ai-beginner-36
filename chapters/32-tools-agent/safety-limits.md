# 本章安全限制清单

这是当前示例代码的具体约束，面向固定教学资料和短任务。

| 项目 | 当前约束 | 验证依据 |
|---|---|---|
| 工具权限 | 仅计算器和只读搜索 | 未知工具及整批拒绝测试 |
| 文件范围 | 第31章三份资料和已校验索引 | 文件哈希与模型版本检查 |
| 模型参数 | 不开放路径、网址、命令或密钥 | 精确字段与工具名称检查 |
| 计算输入 | 80字符、25节点、数值与四则运算 | 表达式、除零、数值边界测试 |
| 搜索输入 | 1至200字符的问题 | 实际检索及长度测试 |
| 工具预算 | 全任务最多4次，重复参数停止 | 上限测试及真实失败记录 |
| 模型预算 | 最多6轮，历史6000字符 | 最后一步及截断测试 |
| 时间 | HTTP单次30秒，步骤边界60秒 | 本地确定性时间检查 |
| 响应 | 最多2MB，结构和用量检查 | 本地 HTTP 及无效响应测试 |
| 写记录 | 程序固定写入本章 results | 命令行入口不接收保存路径 |
| 来源文字 | 作为不可信数据处理 | 系统说明及工具权限共同限制 |

时间检查不会硬取消执行中的请求或编码。消息字符预算也不是服务端 Token 预算。真实模型仍可能误解资料、粗略标注行号或过早结束；本章保留原始结果，人工核对最终事实。教学例子没有开放发送消息、删除资料或对外发布动作。

## 数据与请求范围

搜索沿用第31章原创虚构柳叶学习室资料，不对应真实机构。Embedding 在本机运行，选中的工具片段与问题会进入下一次 API 请求。不要将私人资料、账号信息或密钥放入本章示例资料。

`teaching_replay.py` 中的回复、Token 数和固定搜索文本均由作者编写，用于验证控制器分支，不表示实际模型运行结果。真实模型运行只见 `live-agent` 记录，停止的失败请求也计入实际用量。
