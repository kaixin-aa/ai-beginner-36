# 教学文本与人工向量

2026 年 10 月 3 日自行编制八条虚构教学句子、26 个词的四维向量，以及六个英文词的频次。没有外部语料、用户私人文本或模型权重。语句只用于切分和计算演示，不承担现实事件陈述。

四维分别为电脑与编程学习、猫与家具、下雨与雨具、购物与水果。词向量人工指定，并未根据语料训练。功能词与部分动词设为零，猫和家具合并为同方向，故意保留表示粗糙和否定信息遗漏的可观察反例。

词表编号按 Token 字符串排序。句向量取 Token 向量均值，字符向量按整个句子集合中的同一字符表统计，两个方法都丢失词序。相似度仅计算非零向量方向，不能代表真假或事实支持。

BPE 训练采用 low、lower、lowest、new、newer、newest，频次为 5、2、1、3、2、1，执行六轮合并。并列按字典序选，词内合并，不含字节回退。newlow 为未见组合字符串，仅用于检查复用已有片段。

本章结果表是对上述设定的真实计算，既不是自然语料统计，也不是预训练语义模型的性能数据。
