# 第 28 章术语表

| 术语 | 本章含义 | 容易混淆的边界 |
|---|---|---|
| 语料 | 用于准备训练的文本集合 | 可访问不等于所有用途都已获许可 |
| 预训练 | 从一般文本等数据学习基础表示与预测规律 | 本章聚焦自回归下一 Token 目标 |
| 指令微调 SFT | 用任务与示范输出继续更新已有模型 | 提示文字进入一次对话不自动等于微调 |
| 偏好数据 | 同任务候选与优劣比较 | 评分标准和标注来源都需说明 |
| 奖励模型 | 估计候选是否符合训练偏好 | 评分不直接保证事实正确 |
| RLHF | 用人类反馈参与的奖励信号优化模型的一类路线 | 不是所有偏好训练的统一实现 |
| RLAIF | 用 AI 反馈参与训练信号的路线 | AI 评价仍需规则和评估 |
| DPO | 直接利用偏好对优化的一种方法 | 无需将所有过程都做成单独奖励模型加 RL |
| 推理 | 固定参数下计算输出 | 本章与反向传播更新明确分开 |
| 温度 | 抽样前缩放类别分数的正数 | 改变分配，不能自动补充知识 |
| 贪心 | 每一步取最高分项 | 本章正温度不会改变候选排序 |
| top-k | 每一步只保留最高 k 项再选择 | 不表示 k 条预先写好的完整答案 |
| 上下文 | 当前输入序列和历史信息 | 长度限制需按具体模型与配置核对 |
