# 第 29 章教学数据说明

固定响应由作者编制，见[教学服务代码](../examples/local_fixture.py)。回答文本、响应编号、模型标记和输入 30、输出 18、合计 48 个 Token 均为设定值。它们来自本地固定服务，没有经过大模型生成或平台计量。

本地服务只接受教学占位符，只绑定 127.0.0.1，测试中的限流、无效 JSON 和超时由服务主动模拟。客户端确实完成 HTTP 传输，但没有验证真实平台认证与生成能力。

以后真实 API 调用记录应使用 `kind` 为 `live_api` 的独立文件，保留请求问题、生成文本、服务返回用量及结束原因。不要混入固定响应文件，不要保存密钥或完整认证头。
