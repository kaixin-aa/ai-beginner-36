# 教学数据字段说明

全部记录由本项目原创编写，不含真实个人数据。原始 CSV 与 Excel 保存相同的八条记录。标题仅代表学习主题，不是正式课程成绩。

| 字段 | 原始含义 | 清洗规则 |
|---|---|---|
| record_id | 一次学习记录的 ID | 去两端空格并转大写，缺失拒绝；同 ID 内容冲突时全部转入待核对 |
| title | 学习主题 | 去两端空格，空标题拒绝 |
| done | 完成状态文字 | 去空格并转小写，仅 true 与 false 可映射为布尔值 |
| minutes | 本次记录的分钟数 | 转数值，允许 0 到 1440；空白与非数值内容保留为缺失并标明原因 |
| tag | 分类标签 | 去两端空格并转小写，空标签可以保留 |
| source_row | 本章源文件物理行号 | 原始表头占一行，首条记录为第 2 行；当前 CSV 没有单元格内换行 |
| minutes_status | 分钟数质量标记 | known 为有效数值，missing 为原来空白，invalid_text 为非空但不能转换 |
| reason | 拒绝原因 | 仅拒绝表具有此列，允许记录多个原因 |

原始 CSV 将全部字段按字符串读取，保留空白和数字文字，以便发现格式问题。清洗后 minutes 使用 Pandas 可空浮点类型 Float64，done 使用可空布尔类型 boolean。CSV 文件不保存这些类型信息，再读取时需要重新指定或转换。

本章按标准化后的五个原始字段判断完全重复，保留第一次出现的记录。source_row 不参与重复比较。两个重复来源行为第 5 与第 9 行，非法负分钟数来源行为第 8 行。

“二十”不按程序猜成 20，转为未知分钟数并保留 invalid_text。0 表示明确记录了零分钟，缺失表示当前不知道时长，两者分别保存。
