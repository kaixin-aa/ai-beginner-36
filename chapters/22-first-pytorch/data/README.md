# 第 22 章原创教学数据

输入、标签与噪声均由作者为教学生成，没有真人信息或业务来源。生成日期为 2026 年 10 月 3 日。完整生成程序见 `../examples/torch_core.py`，种子为 42。

41 个输入均匀分布于 -1 至 1，数值类型 float32。按 `y = 2x + 1 + 噪声` 生成目标，噪声设定为均值零、标准差 0.05 的正态随机数。随后用同一个 NumPy 生成器打乱位置，前 32 条作训练，后 9 条作测试。

| 字段 | 含义 |
|---|---|
| sample_id | 从零开始的教学编号，不进模型 |
| x | 单个输入数值，无物理单位 |
| y | 带噪声目标数值，无物理单位 |
| split | 固定训练或测试用途 |
| prediction | 本次模型输出，数据生成后才增加 |

主程序重新生成 CSV，随章固定结果见[数据文件](./teaching_line.csv)。模型只使用训练位置的 x、y 更新，prediction 和编号不作输入。没有把教学关系描述成现实规律，结果只限当前生成范围。

正文三条无噪声数据、改成 `3x - 2` 的练习与九参数求导例子也为原创教学设定，分别运行，不混入上述 41 条数据的测试指标。
